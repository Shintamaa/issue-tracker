# Issue Tracker

Open-source issue tracker for small development teams. Built with Laravel and modern web technologies.

## About The Project

This application is designed to help small development teams manage projects, track tasks, and streamline collaboration efficiently.

## Tech Stack

- **Backend:** Laravel (API, Sanctum Authentication, Eloquent ORM)
- **Database:** MySQL / PostgreSQL
